# YuMeew Music Studio

YuMeew 是以純 HTML、CSS 與原生 JavaScript 製作的瀏覽器音樂視覺工作室。你可以加入音樂、背景素材與字幕，製作頻譜或黑膠動畫，再輸出成影片或音訊。

[立即使用 YuMeew](https://the-music.app/)

## 主要特色

- 音樂解碼、預覽、裁剪、繪圖與媒體編碼皆在瀏覽器內完成。
- 支援 16:9、9:16，以及 480p、720p、1080p 和 30／60 fps。
- 提供 30 種節奏樣式（包含黑膠唱片），以及不顯示動畫的「無」。
- 可加入歌曲資訊、字幕和個人識別，並直接繪入輸出影片。
- 可輸出 MP4、MOV、WebM、MP3、M4A、FLAC 與 WAV。
- 常用設定與媒體可保存在目前瀏覽器，重新開啟後繼續使用。
- 支援 [Supabase](https://supabase.com/) Auth 與 Google OAuth 會員登入，可查看剩餘額度、儲值紀錄與消費紀錄。
- 網站本體可由 GitHub Pages 靜態部署；本機媒體仍保存在使用者的瀏覽器。

## 會員功能

所有頁面右上角會顯示會員頭像與剩餘額度，點擊即可進入會員中心。未登入時可使用 Google OAuth 登入；會員中心會分別列出儲值及消費紀錄。

會員身分由 [Supabase](https://supabase.com/) Auth 管理；會員資料、額度與交易紀錄保存在 Cloudflare D1。瀏覽器只能將 Supabase 登入 JWT 送至會員 Worker，無法直接存取 D1。儲值與扣款另由具備 Worker 管理密鑰的可信任服務執行。Supabase 設定方式位於 [`supabase`](./supabase) 目錄，會員 Worker 位於獨立的 `member-api` Git 專案。

## 音樂視覺工作室

主畫面提供完整的素材、預覽和輸出流程。

### 素材與畫面

- **音樂**：載入瀏覽器可解碼的 MP3、WAV、M4A、FLAC 等音訊。
- **背景素材**：支援 JPG、PNG、WebP，以及靜音循環播放的 MP4、MOV、WebM。
- **歌曲資訊**：可設定歌曲名稱、作詞、作曲、顏色、大小、位置及淡出時間。
- **字幕**：支援 SRT、ASS、含時間碼的 TXT，並可調整位置、方向、字型、大小（100%～500%）、文字色與描邊色。
- **個人識別**：可使用文字或圖片，調整位置、縮放、不透明度、字型與顏色。
- **畫面設定**：可調整頻譜色彩、強度、水平／垂直位置及背景暗度。

上傳內容若無法讀取，對應區域會以紅框顯示錯誤原因。

### 節奏動畫

節奏選單預設收起，包含「無」與下列 30 種動畫：

環形脈衝、經典音柱、鏡像頻譜、流動波形、放射光芒、點陣節奏、同心漣漪、星旋軌跡、層疊聲浪、律動星塵、雙螺旋、節拍隧道、霓虹山脈、花瓣律動、音浪瀑布、菱晶脈搏、軌道行星、電流震盪、黑膠唱片、粒子噴泉、光譜地平線、旋轉風車、蜂巢脈動、極座標玫瑰、音階階梯、液態氣泡、織網脈絡、極光帷幕、心電脈動、幾何萬花筒。

黑膠模式可另外上傳封套和唱片封面。播放開始時唱片會從封套滑出，接著以每分鐘 33⅓ 轉順時針旋轉。

### 播放與裁剪

- 即時預覽可點擊放大至全螢幕，再點一次恢復。
- 播放列支援跳轉、循環播放及裁剪範圍標記。
- 裁剪時間使用 `分:秒.百分秒`，可輸入數值或直接拖曳色帶與端點。
- 色帶顯示選取總長度，放開後自動套用。
- 播放與輸出音量可在 10%～200% 間調整。
- 三段 EQ 可調整低音、中音和高音，套用於試聽與輸出。

裁剪只決定播放和輸出範圍，不會修改原始音樂。

### 字幕編輯器

獨立字幕編輯器提供：

- 音訊波形與可拖曳的字幕時間帶。
- 新增、刪除、複製及逐句編輯字幕。
- 起訖時間 ±0.1 秒、±0.5 秒快速調整。
- 最多 10 次復原與重做。
- 標準 SRT 下載，以及保存後直接覆寫主畫面字幕。
- 中文、日文、英文 AI 字幕辨識。

AI 辨識會先在瀏覽器用 Spleeter 分離人聲，再將衍生的人聲處理成單聲道、16 kHz、16-bit PCM WAV，送往字幕辨識服務。若已有字幕，開始前會先詢問是否覆寫。

## 獨立工具

### 圖片生成

輸入文字後可使用 Flux.2 Klein 4B、GPT-Image-2.5 Flare 或 GPT-Image-2.5 Sunburst 生成 1280 × 720 圖片。

- 支援題詞補全、生成進度、全螢幕預覽與圖片下載。
- 最後一次生成結果保存在 IndexedDB。
- 只有按下「套用主畫面背景」才會取代目前背景素材。
- 需要金鑰的模型會依服務供應商共用 API KEY，並保存在目前瀏覽器的 `localStorage`。

### 影片生成

支援 MiniMax H3、Seedance 2.0、Seedance 2.5 與 Veo 3.1 Preview。

- 可編寫影片細節、建立分鏡及人物模板。
- 「新增分鏡」開啟後會暫時鎖定入口；分鏡視窗可縮小並從右下角繼續編輯，輸入內容不會清除。
- 已加入的分鏡以卡片呈現，可點選重新編輯、複製或刪除。開始與結束時間只接受一位小數，新增或複製的分鏡會自動接續上一張的結束時間；複製時會保留原本的分鏡長度。
- 分鏡卡片可用上移、下移調整順序，並可依目前順序從 0 秒重新接續全部分鏡時間。
- 可在分鏡列表上方開啟唯讀題詞預覽，確認實際送往模型的完整純文字內容與引用人物資料。
- 分鏡支援場景、鏡頭、視角、燈光、動作、對白與音效。視角可組合景別、觀看角度、複數畫面主體與第一人稱／越肩視點角色；動作可指定執行角色、類別、內容、速度／力度、目標與連續動作；鏡頭可從常用運鏡選單選擇速度；燈光可選擇 30 種常用布光、色溫與強度，各項仍可使用開放式文字輸入補充。
- 可引用圖片、音訊、影片及已啟用的人物資料。
- 生成結果可預覽、下載或套用為主畫面背景。
- 生成前會整理模型、輸出規格、片長、分鏡、人物、資源與額度來源；分鏡檢查也會提示相鄰鏡頭的時間、場景、天氣、燈光與人物服裝連續性。
- 分鏡 AI 分析優先呼叫 `storyboard-checker` Worker（Cloudflare Workers AI），失敗時自動退回 `inspiration-chat` Worker（改代理 OpenRouter 的 Nex-N2.5-Pro 免費模型；這顆 Worker 原本是已下架的「靈感激發」聊天頁面後端，目前先保留當備用引擎）當備援，使用者不會感覺到差異。
- 生成任務 ID 會暫存至 IndexedDB，重新整理或稍後回到頁面時可繼續查詢。最近 10 個成功結果可保留為生成歷史、載入或選取兩個版本並排比較。
- 生成歷史與人物模板保存在 IndexedDB；臨時引用資源不會持久保存。

### 人聲分離

可將最長 8 分鐘、150 MB 以內的音樂分離成人聲與伴奏。

- 可選輕量 Spleeter 2-stems 或 BS PolarFormer 高品質模型。
- 優先使用 WebGPU，無法使用時回退至 WASM CPU。
- 分離後提供兩條同步播放的頻譜音軌。
- 每軌有獨立 MUTE、−10～+10 dB 音量及三段 EQ。
- 人聲軌提供瀏覽器端自動調音。
- 可分別下載音軌，或重新混合成 WAV 後下載／套用到主畫面。

模型檔首次使用時下載並保存至 IndexedDB，音樂與分離結果不會上傳。

### 圖轉影片

可依序加入多張圖片或影片素材，為每個項目設定持續時間、順序、進場和退場特效。

- 啟用透明通道時輸出 PNG 編碼 MOV。
- 關閉透明通道時輸出 MP4，以降低檔案大小。
- 解析度、FPS 與畫面比例預設沿用主畫面。
- 可下載成品，或編碼完成後直接套用為主畫面背景。

### 影片編輯

主畫面的影片本體會成為鎖定的基礎圖層，字幕與個人識別固定在最上層。中間可加入影片或圖片圖層，設定時間、順序、音訊，以及各一個進場與退場特效。

套用回主畫面時只編碼可編輯圖層，沿用主畫面的解析度與 FPS，並把主畫面的節奏動畫改為「無」。

### 其他工具

主畫面頂端的「其他工具」選單包含：

| 工具 | 功能 |
| --- | --- |
| 任意轉 | 在瀏覽器內轉換影片與音訊格式 |
| AI 母帶 | 規則式多頻段動態壓縮＋響度正規化＋即時 EQ 調整器，將音樂處理到指定的目標響度與峰值上限 |
| 歌曲評分 | 使用 Suno 分享連結，以 APEX 模型進行單曲評分或雙曲比較 |
| Suno 工具 | 解析公開 Suno 分享連結，在瀏覽器解碼並轉成 WAV |

歌曲評分模型在本機執行，音樂不會送往評分伺服器。Suno 分享連結只保留在當前輸入框，不會寫入 `localStorage` 或 IndexedDB。
評分頁透過 Service Worker 啟用跨來源隔離，頁面與工作程序載入時均套用對應標頭，讓支援的瀏覽器使用 WASM 多執行緒。

任意轉失敗時會依實際原因顯示訊息：來源影片／音訊編碼無法被目前瀏覽器解碼（例如舊版瀏覽器或未內建對應編碼器）會提示改用最新版 Chrome 或 Edge；MP3 與 FLAC 輸出使用內建的軟體編碼器（透過 Worker 執行的 WASM），非瀏覽器原生支援格式時才會啟用。

AI 母帶另外提供「人聲清晰度」與「背景音震撼度」兩個各 5 段的 EQ 滑桿：正中間是預設（不調整），往左減弱、往右增強，每段間距達 3.5 dB，5 段彼此之間都聽得出明顯差異。因為處理的是母帶混音後的完整音樂、不是真正的人聲分離，兩者分別用 peaking 濾波器（約 3.2 kHz，人聲子音與泛音集中的頻段）與 low-shelf 濾波器（約 110 Hz，低頻量感）去逼近，會在多頻段壓縮之前套用，所以最終響度與峰值仍會照樣被正規化與限幅、不受 EQ 調整影響。

AI 母帶的原音試聽播放器支援即時預覽：播放時會用瀏覽器內建的 Web Audio 節點（peaking／low-shelf 濾波器＋單頻段動態壓縮器＋響度增益）即時套用目前的目標響度、壓縮強度、人聲清晰度、背景音震撼度設定，邊調整滑桿邊聽得出差異，不用等到按下「開始處理」才知道效果；這只是聽感方向的近似，正式輸出仍然是「開始處理」之後跑一次完整的離線演算法（4 段分頻壓縮＋ITU-R BS.1770-4 響度正規化＋True Peak 限幅），兩者不會互相影響。原音試聽播放器下方也會畫出整段音樂的波形圖，播放時同步顯示目前播放到哪裡，並提供「循環播放試聽」開關（預設開啟，不寫入任何暫存，每次打開頁面都會重置）。

AI 母帶的響度量測依 ITU-R BS.1770-4 規格自行實作（K-weighting＋gated loudness），峰值保護則同時參考 Annex 2 的 True Peak（4 倍過取樣估計取樣點之間的峰值，而非單純掃描取樣點），避免處理後的音樂在轉成 MP3 等有損格式或經過 D/A 轉換時因為抓不到的峰值而爆音。曾評估過改用 [Essentia.js](https://github.com/MTG/essentia.js)（授權同為 AGPL-3.0，本可直接沿用）取代自製 DSP，但它是純分析函式庫、沒有壓縮器／限幅器可用，且 wasm 主體約 2 MB，遠大於現有內嵌的 MP3／FLAC 編碼器（各約 300 KB），因此仍以自行實作為主。

## 輸出規格

| 格式 | 內容 | 編碼 |
| --- | --- | --- |
| MP4 | 影片與音訊 | H.264 + AAC 192 kbps |
| MOV | QuickTime 影片與音訊 | H.264 + AAC 192 kbps |
| WebM | 影片與音訊 | VP9 + Opus 192 kbps |
| MP3 | 純音訊 | MP3 192 kbps |
| M4A | 純音訊 | AAC 192 kbps |
| FLAC | 純音訊 | FLAC |
| WAV | 純音訊 | 16-bit PCM |

影片尺寸：

| 比例 | 480p | 720p | 1080p |
| --- | --- | --- | --- |
| 16:9 | 854 × 480 | 1280 × 720 | 1920 × 1080 |
| 9:16 | 480 × 854 | 720 × 1280 | 1080 × 1920 |

MP4／MOV 可選自動、Baseline、Main、High H.264 Profile。影片輸出會依序嘗試硬體優先、瀏覽器自動選擇及軟體優先；實際使用 GPU、媒體引擎或 CPU 由瀏覽器與作業系統決定。

| --- | --- | --- |
| 主畫面編輯與匯出 | 瀏覽器 | 無 |
| 任意轉、圖轉影片、影片編輯 | 瀏覽器 | 無 |
| 人聲分離、歌曲評分 | 瀏覽器 | 只下載模型；不送出音樂 |
| AI 母帶 | 瀏覽器 | 無 |
| AI 字幕辨識 | 瀏覽器 + 辨識服務 | 分離後的人聲 WAV、語言、選填歌詞與時長 |

| Suno 工具 | Suno CDN + 解析 Worker | 公開分享連結；Worker 不保存音樂 |
| 分鏡 AI 分析 | storyboard-checker Worker（主要）+ inspiration-chat Worker（備援）+ OpenRouter | 分鏡內容與全片風格；Worker 與模型服務端都不會保存分析內容 |

一般素材限制：

| 素材 | 支援內容 | 限制 |
| --- | --- | --- |
| 音樂 | 瀏覽器可解碼的音訊 | 300 MB、20 分鐘 |
| 圖片 | JPG、PNG、WebP | 每張 30 MB |
| 字幕 | SRT、ASS、含時間碼的 TXT | 5 MB |

媒體輸出在記憶體中產生，處理期間請保持頁面開啟。瀏覽器不支援指定編碼時會顯示錯誤，不會自動改送伺服器轉檔。

## 瀏覽器儲存

- `localStorage`：介面佈景、畫面、字幕、輸出及其他輕量設定；使用者 API KEY 依服務供應商保存在這裡。
- IndexedDB 媒體快取：主畫面音樂、背景素材、字幕、人物模板、草稿及最近生成結果。
- IndexedDB 模型快取：Spleeter、BS PolarFormer、APEX／MERT 等瀏覽器 AI 模型。

設定頁提供「介面」、「金鑰管理」、「快取管理」與「模型管理」。可檢視並刪除保存的金鑰、媒體或模型；模型刪除後會在下次使用時重新下載。

不同網域、瀏覽器與裝置之間不共用資料。大型檔案能否持久保存取決於瀏覽器的可用空間與保留政策。

## 本機開發

需求：Node.js 22 以上。專案沒有 npm 執行期相依套件。

```sh
npm run dev      # 啟動 http://localhost:3000
npm test         # 執行 Node.js 測試
npm run build    # 建立 dist/
npm run preview  # 預覽 dist/
```

網站使用 ES modules，請透過 HTTP(S) 開啟，不要直接使用 `file://`。建置程序會複製公開檔案並加入內容雜湊版本參數。

## 部署

推送至 `main` 後，[GitHub Pages 工作流程](.github/workflows/pages.yml) 會依序執行測試、建立 `dist/` 並部署。正式網站使用自訂網域 [the-music.app](https://the-music.app/)。

`robots.txt` 與 `sitemap.xml` 隨靜態站一起部署，各公開頁面另外帶有 `<link rel="canonical">`、Open Graph 與 Twitter Card 中繼標籤（`og:title`／`og:description`／`og:image`／`og:url`，共用 `icons/og-image.png` 這張 1200×630 社群分享圖）；`account.html`、`admin.html` 屬會員／管理員限定頁面，兩者皆標示 `noindex, nofollow` 並列於 `robots.txt` 的 `Disallow`，不納入 `sitemap.xml`。新增公開頁面時記得同步加進 `sitemap.xml` 與各頁 `<head>` 的中繼標籤。

需要雲端 API 或公開連結解析的功能由獨立的 [model-proxy-worker](https://github.com/YueyuHoshizora/model-proxy-worker) 提供介面。
