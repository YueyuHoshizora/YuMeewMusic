# YuMeew Music Studio

使用純 HTML、CSS 與原生 JavaScript 製作的音樂視覺化工作室。載入音樂、圖片與字幕，製作頻譜或黑膠動畫，並在瀏覽器內匯出影片或音訊。

**線上使用：** [YuMeew Music Studio](https://ezmusic.yustellar.idv.tw/)

主畫面頂部的「文生圖」會開啟獨立的 AI 圖片生成頁面。使用者可先輸入多個詞，以 POST JSON 的 `prompt` 欄位呼叫 `/autocomplete`，再由「組成題詞」將回傳結果覆寫至圖片描述框；圖片生成只會在點擊「生成圖片」後，以 `prompt` 與布林值 `enhance` 呼叫 `/generate`，生成 1280 × 720 JPEG。「文字轉譯成Prompt」預設開啟，會要求服務將輸入文字翻譯並整理成較標準的繪圖提示詞。生成結果只暫存在目前分頁，可直接下載；只有使用者按下「套用主畫面背景」時，才會將圖片保存至 IndexedDB 並取代主畫面的背景素材。頁面會註明每日早上 8 點（台灣時間）重置額度；此功能只會把文字題詞與選項傳送至 `flux-klein-worker.yustellar.idv.tw`，本機媒體不會隨請求上傳。

主畫面頂部的「人聲分離」會開啟獨立的瀏覽器端 AI 工具，並預設從 IndexedDB 帶入主畫面目前保存的音樂；沒有保存音樂時仍可另外選擇檔案。工具可將最長 8 分鐘、150 MB 以內的音樂分離為人聲與伴奏。預設使用輕量 Spleeter 2-stems（兩個模型合計約 75 MB），另可選原本的 BS PolarFormer 高品質模型（約 201 MB）。輕量模型優先縮短處理時間，但可能殘留更多伴奏，約 11 kHz 以上頻段保留於伴奏。功能優先使用 FP32 WebGPU 模型，無法使用時自動改以 WASM CPU 執行；程式會轉換 FP16 模型輸出並攔截無效數值與全靜音結果，GPU 輸出無效時會自動改用 WASM CPU 重新處理。完成後會產生人聲與伴奏兩個同步動畫頻譜，使用共用的播放鍵與播放位置同時播放；每條音軌仍有獨立 MUTE、-10～+10 dB／0.3 dB 步進的音量，以及 −24～+24 dB 的低、中、高音三段 EQ（300 Hz 低頻棚架、1 kHz 寬中頻、3 kHz 高頻棚架），並透過 Web Audio 即時套用於聲音與頻譜。設定會保存在瀏覽器並套用於試聽。可下載未經調整的獨立人聲／伴奏，也可將目前 MUTE、音量與 EQ 套用到兩軌後重新混合，經整體峰值保護後下載 44.1 kHz、16-bit 立體聲 WAV。「套用到主畫面」會將同一份混合 WAV 保存到 IndexedDB、取代主畫面的音樂並自動返回，媒體不會上傳。第一次執行會從 Hugging Face 下載所選模型（Spleeter 使用 FP32；BS PolarFormer 的 CPU 回退使用 FP16），並保存到 `yumeew-ai-models-v1` IndexedDB。舊版 Cache Storage 中的模型會在首次使用時自動移入 IndexedDB。同一頁面後續分離還會沿用已建立的 GPU／CPU 模型工作階段，避免再次載入與暖機。選擇的音樂、PCM 資料與分離結果都不會上傳。

主畫面頂部的「任意轉」會開啟獨立媒體轉換頁面。影片輸入明確支援 WebM，以及 MP4、MOV 等瀏覽器可讀格式，可轉成 MP4、MOV、WebM、MP3、M4A、FLAC 或 WAV；音樂輸入僅提供 MP3、M4A、FLAC 與 WAV。頁面會依實際媒體軌限制選項，轉換與下載全程在瀏覽器完成。

「圖轉影片」可一次加入多張 JPG、PNG、WebP 圖片，依序調整每張圖片的持續時間、進場特效、退場特效及特效時間。解析度、FPS 與畫面比例預設沿用主畫面設定；輸出固定為採用 PNG 影格的 MOV，因此 PNG 透明通道會保留。可直接下載 MOV，也可選擇「匯出到主畫面」；完成編碼與瀏覽器保存後，成品會取代主畫面的背景素材並自動返回。主畫面另保存圖片時間軸資料，以便在瀏覽器無法直接播放 PNG 編碼 MOV 時仍能循環預覽及匯出。

「圖轉影片」右側的「影片編輯」會開啟獨立影片圖層編輯器。主畫面保存的音樂視覺作品會自動成為鎖定且不可編輯的最底層「主畫面影片本體」，沿用音樂、背景素材、節奏動畫、比例與畫面設定。可在中間加入多段 MP4、MOV、WebM 影片與 JPG、PNG、WebP 圖片，調整各圖層在時間軸上的順序與開始時間；影片可設定結束時間及是否包含音訊（預設關閉），圖片可設定持續時間。主畫面的字幕與個人識別也會自動帶入，固定繪製在所有素材上方且不允許改變層級。預覽、解碼、音訊混合與 MP4／WebM 匯出全程在瀏覽器完成。

影片編輯的開始與結束時間各有 `+0.5`、`+0.1`、`−0.5`、`−0.1` 秒按鈕，可快速微調選取的影片圖層。播放控制列的滑桿可拖曳定位，時間軸空白區也可點擊或按住拖曳播放頭，預覽會同步更新。預覽下方另有預設收起的「影片裁剪」，可使用分秒欄位、範圍滑桿或拖曳色帶及兩端選取最終影片範圍；放開後自動套用，預覽、字幕、圖層音訊與匯出都使用相同範圍。

每個影片或圖片圖層可各選一個進場特效與一個退場特效，持續時間預設為 `0.5` 秒，並可透過數值欄位在 `0.1～10` 秒之間調整。可用特效包含淡入淡出、交叉溶解、四向滑動、放大進入／縮小離開、模糊、閃白、閃黑、圓形揭露／收合、百葉窗、像素化與 RGB 色差故障；即時預覽與 MP4／WebM 匯出使用相同效果。

## 隱私與檔案限制

所有媒體讀取、解碼、裁剪、繪製、AI 分離與匯出都在客戶端完成。沒有媒體上傳 API、雲端轉碼或遠端媒體儲存；編碼器、ONNX Runtime 與 WASM 隨網站提供。全站所有遠端模型檔都統一自動保存到 `yumeew-ai-models-v1` IndexedDB：Spleeter 與 BS PolarFormer 第一次由瀏覽器從 Hugging Face 下載，之後可直接使用本機快取，音樂不會傳送至該服務。文生圖是唯一的雲端 AI 例外：只傳送使用者輸入的圖片描述，並接收生成的 JPEG，不傳送既有媒體檔案。

主畫面頂端的「設定」會開啟獨立設定頁面；各項功能排列在左側導覽列，目前提供「模型管理」。模型管理會列出 IndexedDB 中每套 AI 模型的名稱、來源、合計容量與快取檔案數。可逐一刪除模型或刪除全部模型；每次刪除前都會提示下次使用時必須重新下載。這項操作只清除 AI 模型，不影響音樂、背景素材、字幕與其他網站設定。

| 素材 | 支援內容 | 限制 |
| --- | --- | --- |
| 音樂 | 瀏覽器可解碼的音訊，例如 MP3、WAV、M4A、FLAC | 300 MB、20 分鐘以內 |
| 圖片 | JPG、PNG、WebP | 每張 30 MB |
| 字幕 | SRT、ASS、TXT，UTF-8 編碼 | 5 MB |

載入失敗時，上傳區會顯示紅框與錯誤原因。輸出檔案在記憶體中產生，匯出期間請保持頁面開啟；不支援的編碼會顯示錯誤，不會改送伺服器處理。

## 創作與預覽

- 固定桌面三欄配置，不提供手機／平板 RWD；窄視窗使用水平捲動。
- 即時預覽與播放控制保持在頂端，節奏選項區可獨立捲動。
- 點擊即時預覽可放大至瀏覽器全螢幕，再點一次即可恢復；亦支援 Enter 與空白鍵操作。
- 支援 16:9 橫式與 9:16 直式，預覽依比例調整大小。
- 左側預設收起的「畫面設定」可調整頻譜色彩、強度、水平／垂直位置及背景暗度。
- 提供日／夜模式與青檸、海藍、紫羅蘭、玫瑰、琥珀五種介面主題。

### 節奏樣式

右側欄位上方的「選一種節奏」預設折疊，標題後方的箭頭會提示展開方向並隨狀態旋轉。展開後以三欄小型按鈕提供 **19 種動畫**，另有排在第一個的「無」選項；匯出設定排列在節奏選項下方。收起區塊不會改變已選擇的節奏。選擇「無」會保留背景、音樂、歌曲資訊與字幕，不繪製頻譜動畫。

環形脈衝、經典音柱、鏡像頻譜、流動波形、放射光芒、點陣節奏、同心漣漪、星旋軌跡、層疊聲浪、律動星塵、雙螺旋、節拍隧道、霓虹山脈、花瓣律動、音浪瀑布、菱晶脈搏、軌道行星、電流震盪、黑膠唱片。

### 黑膠唱片

播放前 2 秒，唱片從封套滑出，之後以每分鐘 33⅓ 轉順時針旋轉；暫停時停止。選擇此模式後，創作素材會顯示兩個獨立圖片欄位：

- **黑膠封套**：方形封面；未指定時沿用背景素材的目前畫面，無背景素材時使用預設圖案。
- **唱片封面**：唱片中央的圓形標籤，隨唱片旋轉。

預覽、拖曳播放進度與匯出使用相同的動畫時間計算。

### 歌曲資訊

歌曲名稱、作詞、作曲及文字設定位於預設收起的「歌曲資訊與文字設定」內。

- 調整文字顏色、水平／垂直位置及字體大小。
- 「幾秒後淡出」範圍 1～15 秒，預設 5 秒；到達指定時間後，以 1 秒逐漸淡出。
- 歌曲資訊會繪入匯出影片，裁剪後從片段起點重新計算動畫與淡出時間。

## 個人識別

左側「創作素材」提供預設收起的「個人識別」折疊選單。展開後可選文字或圖片識別，並使用水平／垂直位置滑軸；兩種模式共用 0%～100% 的不透明度滑桿，預設 100%。文字模式可在 50%～300% 間調整大小，並提供與字幕相同的字型清單，以及獨立的文字與框線顏色調色盤；預設為系統字型、100%、白字黑框。圖片可在 10%～300% 間縮放，預設 100%。識別內容會繪入預覽與匯出影片。識別圖片會縮至最長邊 512 像素、保留透明度，以 PNG 資料保存在本機 localStorage，下次開啟自動還原；可移除，重置設定也會清除。

## 音樂裁剪

音樂上傳區下方提供預設收起的「音樂裁剪」。載入音樂後，可透過時間欄位、滑軸或播放條上的色帶設定範圍。

- 時間格式為 `分:秒.百分秒`，例如 `01:30.25`。
- 播放條顯示原始音樂時間軸、裁剪起訖標記與範圍色帶；色帶中央顯示選取總長度。
- 播放列的循環按鈕可重複播放完整音樂或目前套用的裁剪範圍，啟用狀態會保存在 Web Storage。
- 拖曳色帶中央可整段平移，拖曳左右端點可調整開始／結束時間。
- 拖曳放開後自動套用；修改時間欄位並完成輸入後也會套用，仍保留「套用裁剪」按鈕。
- 可用方向鍵微調色帶與端點：每次 0.1 秒，按住 Shift 每次 1 秒。
- 匯出前會同步尚未套用的範圍，音訊及影片只輸出選取片段。例如 `00:10～00:30` 輸出 20 秒。
- 「恢復完整音樂」恢復全長播放與匯出，**保留開始／結束欄位與色帶範圍**，方便再次套用。

裁剪不修改原始檔案。更換音樂時，裁剪範圍會重新初始化。

## 字幕

「創作素材」中的「字幕設定」折疊選單預設收起，展開後可上傳、移除字幕並調整所有字幕外觀。字幕依**原始音樂時間碼**顯示，裁剪後會對應原始片段時間；預覽與 MP4／MOV／WebM 匯出皆會將字幕繪入畫面。

主畫面的「開啟字幕編輯器」會進入獨立工作頁面。字幕清單右上角使用「＋」從目前播放時間新增字幕，並使用「−」刪除手動選取的字幕。編輯器可在音訊波形時間軸上點擊跳轉、拖曳整句字幕或左右邊界，也能直接修改每句的開始時間、結束時間及文字；開始與結束時間各提供 ±0.5 秒及 ±0.1 秒的快速微調。播放時只標示目前字幕，不會切換手動選取的字幕或捲動字幕清單；尚未選取或尚無字幕時，時間軸與波形仍會持續顯示，編輯欄位保持空白。底部固定操作列會一直顯示「復原」與「恢復」按鈕，可處理最近 10 次新增、刪除、複製、時間、文字與拖曳操作；鍵盤快捷鍵仍可使用。另支援逐句播放與下載 SRT。按下「儲存並返回主畫面」後，會產生如 `YuMeew字幕_20260908_153045.srt` 的時間戳記檔名，以標準 SRT 覆寫 IndexedDB 中目前的字幕；回到主畫面後，上傳區會顯示這個新檔名並自動套用於預覽和影片匯出，避免與匯入的舊檔案混淆。ASS 與含時間碼的 TXT 匯入後同樣以 SRT 資料編輯，不保留 ASS 樣式。

| 格式 | 解析方式 |
| --- | --- |
| SRT | 依起訖時間碼顯示，支援多行文字 |
| ASS | 讀取 Events 中的文字與時間，忽略樣式、定位與特效；不渲染繪圖指令 |
| TXT | 支援 `[00:12.50] 字幕文字`、`00:12.50 字幕文字` 或 SRT 式起訖時間碼 |

TXT 必須包含有效時間碼，**不會按行數平均分配時間**。只有起點的字幕會顯示到下一個時間點，最後一筆顯示到音樂結束。

字幕的文字與描邊顏色可分別使用調色盤選擇，預設為白字黑色描邊；不加黑色底板，橫排與直排皆適用。

字幕外觀設定：

- **位置**：靠上、靠下、靠左、靠右、置中。
- **邊界距離**：0～40%，提供同步的數字框與滑軸；置中時隱藏。
- **顯示方向**：水平橫排，或由上至下、由右至左換欄的垂直直排。
- **字型**：青松手寫體與莫大毛筆體由網站內建，不需安裝；另有系統預設、微軟正黑體、蘋方、思源黑體／宋體、新細明體、標楷體、Arial、Times New Roman、Courier New。本機未安裝的系統字型會套用替代字型。
- **顏色**：文字顏色與邊框顏色可分別選擇，預設為白色文字與黑色邊框。
- **字體大小**：100%～250%，預設 100%。
- **逐字顯示**：預設關閉，開啟後依每句字幕的起訖時間逐字出現；橫排、直排與匯出皆適用。

## 輸出格式與硬體加速

| 格式 | 內容 | 編碼 |
| --- | --- | --- |
| MP4 | 影片與音訊 | H.264 + AAC |
| MOV | QuickTime 影片與音訊 | H.264 + AAC |
| WebM | 影片與音訊 | VP9 + Opus 192 kbps |
| MP3 | 純音訊 | MP3 192 kbps，本機 LAME WASM |
| M4A | 純音訊，MP4 音訊容器 | AAC 192 kbps |
| FLAC | 純音訊 | 本機 libFLAC WASM |
| WAV | 純音訊 | 未壓縮 16-bit PCM |

影片可選 480p／720p／1080p、30／60 fps，預設 **1080p、60 fps**：

| 比例 | 480p | 720p | 1080p |
| --- | --- | --- | --- |
| 16:9 | 854 × 480 | 1280 × 720 | 1920 × 1080 |
| 9:16 | 480 × 854 | 720 × 1280 | 1080 × 1920 |

480p 使用接近 16:9 的偶數尺寸，供 H.264 編碼；影片目標位元率分別為 2、4、8 Mbps。

MP4／MOV 可選 H.264 Profile：自動、Baseline、Main、High，預設自動；WebM 使用 VP9，因此會隱藏 H.264 Profile。選擇純音訊格式時，Profile、解析度與影格率欄位會全部隱藏。Level 依解析度與影格率自動選擇，指定 Profile 若不受支援會提示錯誤，不會靜默換成其他 Profile。

MP4／MOV／WebM 匯出會針對輸出編碼、尺寸、位元率與影格率偵測能力，依序嘗試硬體優先、瀏覽器自動選擇、軟體優先。Mac 使用相同流程。硬體偏好是 WebCodecs 提示，實際使用 GPU、專用媒體引擎或軟體由瀏覽器決定，無法保證整個匯出流程都在 GPU 執行。介面會顯示選用的編碼偏好。

「任意轉」在影片編碼不同於來源時也會先偵測相同三種加速模式。例如 MP4 轉 WebM 時，若 VP9 硬體編碼不支援目前尺寸，會自動改用瀏覽器選擇或軟體編碼，不會停在 `prefer-hardware` 錯誤。

純音訊不包含圖片、動畫或字幕，解析度與影格率不適用。MP3 多聲道會轉為立體聲；不支援的採樣率會在客戶端轉為 44.1 kHz。FLAC 不會恢復有損來源已失去的細節。可隨時取消匯出。

左側音樂上傳區下方的「播放與輸出音量」可在 10%～200% 間調整，預設 100%，會同時套用到網站試聽及 MP4、MOV、WebM、MP3、M4A、FLAC、WAV 匯出。試聽超過 100% 時使用瀏覽器 Web Audio 增益；匯出時，超過原始峰值的放大可能觸發削波，程式會將 PCM 樣本限制在有效範圍內。原始檔案不受影響。

## 自動保留設定

使用 `localStorage` 的 `yumeew.settings.v1` 保存經驗證的偏好，包括畫面比例、輸出設定、頻譜外觀、歌曲資訊及其文字設定、字幕外觀與方向、日夜模式與佈景主題。

音樂、背景素材與字幕檔使用 IndexedDB 保存在目前瀏覽器，下次開啟網站時依序自動還原；背景素材可使用 JPG、PNG、WebP 圖片或 MP4、MOV、WebM 影片，影片會靜音循環播放並繪入匯出結果。更換檔案會覆蓋舊副本，移除背景素材或字幕也會刪除其副本。大型媒體能否成功保存取決於瀏覽器與裝置的可用儲存空間，失敗時會顯示提示，但不影響當次使用。網站會嘗試請求持久儲存，最終保留政策仍由瀏覽器決定。

個人識別圖片仍以縮小後的 PNG 資料保存在 localStorage。播放進度與裁剪範圍不保存。不同網址／瀏覽器不共用資料；儲存被封鎖或資料損毀時，網站仍可操作。

## 本機執行與部署

使用 Node.js 22 以上，不需要安裝 npm 相依套件。

```sh
npm run dev      # 本機網站 http://localhost:3000
npm test         # 執行測試
npm run build    # 產生 dist/
npm run preview  # 預覽 dist/
```

使用 ES modules，需透過 HTTP(S) 開啟，不能以 `file://` 直接開啟。建置會複製公開檔案並加入內容雜湊版本參數，避免瀏覽器混用舊版 CSS／JavaScript；沒有轉譯或打包步驟。

[GitHub Pages 工作流程](.github/workflows/pages.yml) 在 `main` 更新時執行測試、建置並部署 `dist/`。只發布公開檔案，不發布 Git 資料或測試原始檔；正式網址為 `https://ezmusic.yustellar.idv.tw/`，相對資源路徑也能支援本機預覽。

## 驗證範圍

測試涵蓋 FFT、各動畫與畫面比例、歌曲資訊與字幕繪製、字幕時間碼、裁剪樣本與範圍、匯出前同步終點、保留裁剪欄位、設定保存、主題對比及硬體編碼偏好的回退。

MP3／FLAC／WAV 測試使用真實本機編碼器產生音訊並重新讀取，驗證格式、聲道與時長。圖轉影片的 MOV 會檢查 QuickTime 容器、PNG 編碼、RGBA 像素格式、影格數與時長；瀏覽器測試涵蓋多圖設定、MOV 匯出、匯出到主畫面及再次輸出 MP4。其他 UI 與 Canvas 測試使用模擬瀏覽器介面；實際 GPU 使用方式仍由瀏覽器與作業系統決定。選用 WebMCP API 以功能偵測註冊，尚未有可用驗證環境。
