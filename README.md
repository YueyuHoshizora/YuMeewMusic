# YuMeew Music Studio

YuMeew 是以純 HTML、CSS 與原生 JavaScript 製作的瀏覽器音樂視覺工作室。你可以加入音樂、背景素材與字幕，製作頻譜或黑膠動畫，再輸出成影片或音訊。

[立即使用 YuMeew](https://ezmusic.yustellar.idv.tw/)

## 主要特色

- 音樂解碼、預覽、裁剪、繪圖與媒體編碼皆在瀏覽器內完成。
- 支援 16:9、9:16，以及 480p、720p、1080p 和 30／60 fps。
- 提供 19 種節奏樣式（包含黑膠唱片），以及不顯示動畫的「無」。
- 可加入歌曲資訊、字幕和個人識別，並直接繪入輸出影片。
- 可輸出 MP4、MOV、WebM、MP3、M4A、FLAC 與 WAV。
- 常用設定與媒體可保存在目前瀏覽器，重新開啟後繼續使用。
- 不需要帳號，網站本體可由 GitHub Pages 靜態部署。

## 音樂視覺工作室

主畫面提供完整的素材、預覽和輸出流程。

### 素材與畫面

- **音樂**：載入瀏覽器可解碼的 MP3、WAV、M4A、FLAC 等音訊。
- **背景素材**：支援 JPG、PNG、WebP，以及靜音循環播放的 MP4、MOV、WebM。
- **歌曲資訊**：可設定歌曲名稱、作詞、作曲、顏色、大小、位置及淡出時間。
- **字幕**：支援 SRT、ASS、含時間碼的 TXT，並可調整位置、方向、字型、大小、文字色與描邊色。
- **個人識別**：可使用文字或圖片，調整位置、縮放、不透明度、字型與顏色。
- **畫面設定**：可調整頻譜色彩、強度、水平／垂直位置及背景暗度。

上傳內容若無法讀取，對應區域會以紅框顯示錯誤原因。

### 節奏動畫

節奏選單預設收起，包含「無」與下列 19 種動畫：

環形脈衝、經典音柱、鏡像頻譜、流動波形、放射光芒、點陣節奏、同心漣漪、星旋軌跡、層疊聲浪、律動星塵、雙螺旋、節拍隧道、霓虹山脈、花瓣律動、音浪瀑布、菱晶脈搏、軌道行星、電流震盪、黑膠唱片。

黑膠模式可另外上傳封套和唱片封面。播放開始時唱片會從封套滑出，接著以每分鐘 33⅓ 轉順時針旋轉。

### 播放與裁剪

- 即時預覽可點擊放大至全螢幕，再點一次恢復。
- 播放列支援跳轉、循環播放及裁剪範圍標記。
- 裁剪時間使用 `分:秒.百分秒`，可輸入數值或直接拖曳色帶與端點。
- 色帶顯示選取總長度，放開後自動套用。
- 播放與輸出音量可在 10%～200% 間調整。
- 三段 EQ 可調整低音、中音和高音，套用於試聽與輸出。

裁剪只決定播放和輸出範圍，不會修改原始音樂。

### 字幕編輯器

獨立字幕編輯器提供：

- 音訊波形與可拖曳的字幕時間帶。
- 新增、刪除、複製及逐句編輯字幕。
- 起訖時間 ±0.1 秒、±0.5 秒快速調整。
- 最多 10 次復原與重做。
- 標準 SRT 下載，以及保存後直接覆寫主畫面字幕。
- 中文、日文、英文 AI 字幕辨識。

AI 辨識會先在瀏覽器用 Spleeter 分離人聲，再將衍生的人聲處理成單聲道、16 kHz、16-bit PCM WAV，送往字幕辨識服務。若已有字幕，開始前會先詢問是否覆寫。

## 獨立工具

### 文生圖

輸入文字後可使用 Flux.2 Klein 4B、GPT-Image-2.5 Flare 或 GPT-Image-2.5 Sunburst 生成 1280 × 720 圖片。

- 支援題詞補全、生成進度、全螢幕預覽與圖片下載。
- 最後一次生成結果保存在 IndexedDB。
- 只有按下「套用主畫面背景」才會取代目前背景素材。
- 需要金鑰的模型會把 API KEY 保存在目前瀏覽器的 `localStorage`。

### 影片生成器

支援 MiniMax H3、MiniMax H3 Max、Seedance 2.0、Seedance 2.5 與 Veo 3.1 Preview。

- 可編寫影片細節、建立分鏡及人物模板。
- 分鏡支援場景、鏡頭、視角、燈光、動作、對白與音效。
- 可引用圖片、音訊、影片及已啟用的人物資料。
- 生成結果可預覽、下載或套用為主畫面背景。
- 最後一次生成影片與人物模板保存在 IndexedDB；臨時引用資源不會持久保存。

離開頁面前會顯示確認視窗，避免誤關造成尚未保存的內容遺失。

### 人聲分離

可將最長 8 分鐘、150 MB 以內的音樂分離成人聲與伴奏。

- 可選輕量 Spleeter 2-stems 或 BS PolarFormer 高品質模型。
- 優先使用 WebGPU，無法使用時回退至 WASM CPU。
- 分離後提供兩條同步播放的頻譜音軌。
- 每軌有獨立 MUTE、−10～+10 dB 音量及三段 EQ。
- 人聲軌提供瀏覽器端自動調音。
- 可分別下載音軌，或重新混合成 WAV 後下載／套用到主畫面。

模型檔首次使用時下載並保存至 IndexedDB，音樂與分離結果不會上傳。

### 圖轉影片

可依序加入多張圖片或影片素材，為每個項目設定持續時間、順序、進場和退場特效。

- 啟用透明通道時輸出 PNG 編碼 MOV。
- 關閉透明通道時輸出 MP4，以降低檔案大小。
- 解析度、FPS 與畫面比例預設沿用主畫面。
- 可下載成品，或編碼完成後直接套用為主畫面背景。

### 影片編輯

主畫面的影片本體會成為鎖定的基礎圖層，字幕與個人識別固定在最上層。中間可加入影片或圖片圖層，設定時間、順序、音訊，以及各一個進場與退場特效。

套用回主畫面時只編碼可編輯圖層，沿用主畫面的解析度與 FPS，並把主畫面的節奏動畫改為「無」。

### 其他工具

主畫面頂端的「其他工具」選單包含：

| 工具 | 功能 |
| --- | --- |
| 任意轉 | 在瀏覽器內轉換影片與音訊格式 |
| 歌曲評分 | 使用 Suno 分享連結，以 APEX 模型進行單曲評分或雙曲比較 |
| Suno 工具 | 解析公開 Suno 分享連結，在瀏覽器解碼並轉成 WAV |

歌曲評分模型在本機執行，音樂不會送往評分伺服器。Suno 分享連結只保留在當前輸入框，不會寫入 `localStorage` 或 IndexedDB。

## 輸出規格

| 格式 | 內容 | 編碼 |
| --- | --- | --- |
| MP4 | 影片與音訊 | H.264 + AAC 192 kbps |
| MOV | QuickTime 影片與音訊 | H.264 + AAC 192 kbps |
| WebM | 影片與音訊 | VP9 + Opus 192 kbps |
| MP3 | 純音訊 | MP3 192 kbps |
| M4A | 純音訊 | AAC 192 kbps |
| FLAC | 純音訊 | FLAC |
| WAV | 純音訊 | 16-bit PCM |

影片尺寸：

| 比例 | 480p | 720p | 1080p |
| --- | --- | --- | --- |
| 16:9 | 854 × 480 | 1280 × 720 | 1920 × 1080 |
| 9:16 | 480 × 854 | 720 × 1280 | 1080 × 1920 |

MP4／MOV 可選自動、Baseline、Main、High H.264 Profile。影片輸出會依序嘗試硬體優先、瀏覽器自動選擇及軟體優先；實際使用 GPU、媒體引擎或 CPU 由瀏覽器與作業系統決定。

## 檔案與隱私

| 功能 | 處理位置 | 會送出的資料 |
| --- | --- | --- |
| 主畫面編輯與匯出 | 瀏覽器 | 無 |
| 任意轉、圖轉影片、影片編輯 | 瀏覽器 | 無 |
| 人聲分離、歌曲評分 | 瀏覽器 | 只下載模型；不送出音樂 |
| AI 字幕辨識 | 瀏覽器 + 辨識服務 | 分離後的人聲 WAV、語言、選填歌詞與時長 |
| 文生圖、影片生成器 | 對應的生成服務 | 題詞、生成設定、引用資源及所需 API KEY |
| Suno 工具 | Suno CDN + 解析 Worker | 公開分享連結；Worker 不保存音樂 |

一般素材限制：

| 素材 | 支援內容 | 限制 |
| --- | --- | --- |
| 音樂 | 瀏覽器可解碼的音訊 | 300 MB、20 分鐘 |
| 圖片 | JPG、PNG、WebP | 每張 30 MB |
| 字幕 | SRT、ASS、含時間碼的 TXT | 5 MB |

媒體輸出在記憶體中產生，處理期間請保持頁面開啟。瀏覽器不支援指定編碼時會顯示錯誤，不會自動改送伺服器轉檔。

## 瀏覽器儲存

- `localStorage`：介面佈景、畫面、字幕、輸出及其他輕量設定；API KEY 也保存在這裡。
- IndexedDB 媒體快取：主畫面音樂、背景素材、字幕、人物模板及最近生成結果。
- IndexedDB 模型快取：Spleeter、BS PolarFormer、APEX／MERT 等瀏覽器 AI 模型。

設定頁提供「介面」、「金鑰管理」、「快取管理」與「模型管理」。可檢視並刪除保存的金鑰、媒體或模型；模型刪除後會在下次使用時重新下載。

不同網域、瀏覽器與裝置之間不共用資料。大型檔案能否持久保存取決於瀏覽器的可用空間與保留政策。

## 本機開發

需求：Node.js 22 以上。專案沒有 npm 執行期相依套件。

```sh
npm run dev      # 啟動 http://localhost:3000
npm test         # 執行 Node.js 測試
npm run build    # 建立 dist/
npm run preview  # 預覽 dist/
```

網站使用 ES modules，請透過 HTTP(S) 開啟，不要直接使用 `file://`。建置程序會複製公開檔案並加入內容雜湊版本參數。

## 部署

推送至 `main` 後，[GitHub Pages 工作流程](.github/workflows/pages.yml) 會依序執行測試、建立 `dist/` 並部署。正式網站使用自訂網域 [ezmusic.yustellar.idv.tw](https://ezmusic.yustellar.idv.tw/)。

需要雲端 API 或公開連結解析的功能由獨立的 [model-proxy-worker](https://github.com/YueyuHoshizora/model-proxy-worker) 提供介面。
